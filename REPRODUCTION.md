# AKGVP Reproduction

## Upstream

Original repository:

https://github.com/nuoxu/AKGVP

This reproduction and the subsequent experimental modifications are based on:

`40ed00d`

The corresponding local Git tag is:

`akgvp-original-40ed00d`

## Data

Large precomputed scene data are stored locally under:

`datasets/Scene_Data/`

These files are required for evaluation but are not tracked by Git.

## Model Weights

Pretrained and experimental model checkpoints are stored locally under:

`trained_models/`

Model checkpoints are not tracked by Git.

## Runtime Outputs

Runtime experiment outputs are stored under:

- `runs/`
- `results/`

Generated outputs are not tracked by Git.

The file:

`bestmodels.txt`

is generated by `full_eval.py` and is also excluded from Git.

## Environment

The original environment specification is provided in:

`environment.yml`

## Evaluation

Main evaluation entry points include:

- `main_eval.py`
- `full_eval.py`

Additional evaluation, diagnostic, and analysis utilities are provided under:

`scripts/`

## Zero-Shot Validation Splits

The zero-shot validation splits are stored under:

`test_val_split/`

including:

- `bathroom_zs_val_22.pkl`
- `bedroom_zs_val_22.pkl`
- `kitchen_zs_val_22.pkl`
- `living_room_zs_val_22.pkl`

## Modifications

This reproduction branch contains modifications to the original AKGVP
navigation, model, and evaluation pipeline.

Detailed experimental configurations and results will be documented as
the experiments are finalized.
